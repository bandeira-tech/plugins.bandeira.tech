# plugins.bandeira.tech

A Claude Code marketplace for [BANDEIRA·TECH](https://github.com/bandeira-tech) plugins.

## Install

```
/plugin marketplace add bandeira-tech/plugins.bandeira.tech
```

Then `/plugin install <name>` for any plugin below.

## Plugins

| Plugin | Description |
|---|---|
| [`b3nd`](./b3nd/) | Learn and develop with B3nd — the shape of the framework and how to think in URIs / programs / handlers. Knowledge only; no rig or MCP. |
| [`pip`](./pip/) | Curate your personal information platform — host and grow a B3nd rig node as MCP, manage targets, and scaffold apps via the `bnd` CLI. |
