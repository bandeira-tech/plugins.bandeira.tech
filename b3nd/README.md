# b3nd — Claude Code plugin

Learn and develop with [B3nd](https://github.com/bandeira-tech) from inside Claude Code.

This plugin is **knowledge only**. It teaches the shape of the framework — Protocol Interface Nodes, Outputs, URIs, programs, handlers — and how to think in it as a developer. It ships no rig and no MCP server.

## What you get

- **Skill `learn`** — what B3nd is, why it looks the way it does, and how to reason in URIs / programs / handlers instead of services and endpoints.

## Want to run a rig?

To actually host and curate a rig node — your personal information platform — install the companion **`pip`** plugin, which wraps the `bnd` CLI as an MCP server and adds commands to manage targets, grow the rig, and scaffold apps.

## Install

```
/plugin marketplace add bandeira-tech/plugins.bandeira.tech
/plugin install b3nd
```
