# Build Web App with a B3nd backend

To build a webapp with b3nd you build your frontend as you want it and use
b3nd clients to receive data from the frontend, and send, read and observe data
from the backend.

Once your app is using b3nd you can plug any number of backends, you can start
with frontend-only development without a server and instead use browser localStorage:
